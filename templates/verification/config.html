Verification Threshold Settings

About the Similarity Thresholds

FANS-C uses two similarity thresholds, not one — see the Decision Reference Guide below for the full policy. In general terms only:

  • Higher thresholds: stricter — conceptually fewer false accepts, more false rejects
  • Lower thresholds: more lenient — conceptually fewer false rejects, more false accepts

These are project-configured defaults, not a validated recommendation for any specific population. FANS-C has not yet run a controlled accuracy/false-accept/false-reject evaluation for this deployment, so no specific FAR/FRR percentages can be quoted here. Final calibration should be based on such an evaluation, not a general rule of thumb.
