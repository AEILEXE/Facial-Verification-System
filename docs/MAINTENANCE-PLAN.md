## 2. Bugs Found and Fixed (Branch 2.0, 2026-05-20)

### 2.1 `requests` Missing from requirements.txt

**File:** `requirements.txt`
**Symptom:** `beneficiaries/sync.py` uses `import requests` inside `_push_beneficiary()`. If `requests` is not installed, the sync function raises `ModuleNotFoundError` when called (offline sync mode only — does not affect normal local operation).
**Fix:** Added `requests>=2.31.0` to `requirements.txt`.

### 2.2 `build_exe.ps1` Reported Wrong Output Path

**File:** `dev/build_exe.ps1`
**Symptom:** The script's summary section referenced `dist\FANS-C` but PyInstaller outputs to `dist\fans_c` (per `fans_c.spec` COLLECT `name='fans_c'`). The Inno Setup script correctly used `dist\fans_c`. Only the summary message was wrong; the build itself produced correct output.
**Fix:** Corrected `$distDir` and the post-build next-steps message to use `dist\fans_c`.

### 2.3 `accounts.decorators` in PyInstaller Hidden Imports

**File:** `dev/fans_c.spec`
**Symptom:** `accounts.decorators` listed as a hidden import but the file `accounts/decorators.py` does not exist in the project. This caused a build warning but not a failure.
**Fix:** Removed the entry from `hidden_imports`.

### 2.4 Spurious Line in `.gitignore`

**File:** `.gitignore`
**Symptom:** Line `=3.1.2` (artifact of a bad copy-paste) and a duplicate `.env` entry.
**Fix:** Removed the spurious line; deduplicated the `.env` entry.

## 8. Known Limitations

1. **Python 3.11 only** — TensorFlow 2.13.1 does not support Python 3.12 or 3.13. Upgrading TF requires testing on a dev machine first.
2. **FaceNet model download required on first use** — keras-facenet downloads ~90 MB on first import from GitHub (`faustomorales/keras-facenet` releases). Requires internet once, for the Windows account that runs FANS-C. Cached in `%USERPROFILE%\.keras-facenet\` (not `~/.keras/`). Pre-populate that folder for offline deployments — note the packaged installer's autostart task runs as SYSTEM, a different account/profile than interactive setup; see `dev/BUILD.md` for this open packaging issue. FANS-C fails closed (blocks verification, never uses a random/mock model) if the real model is unavailable.
3. **SQLite concurrency** — SQLite supports one writer at a time. For multi-server or high-concurrency deployments, switch to PostgreSQL (`USE_SQLITE=False` in `.env`).
4. **Windows long path** — Keep the installation path short (e.g., `C:\FANSC`) to avoid TensorFlow DLL extraction failures due to the Windows 260-character path limit.
5. **Camera requires HTTPS** — The browser camera API (`getUserMedia`) requires HTTPS. Plain HTTP deployments cannot capture faces from client devices.
6. **LAN-only design** — This system is designed for a trusted internal barangay network. Do not expose it to the public internet without a full security review and VPN/WAF infrastructure.
